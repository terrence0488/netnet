# Agent logos

Each listed agent guide in `content/agents/` names its logo here. "Other agent" has none.

| Agent | File |
|---|---|
| Claude | `claude.svg` |
| ChatGPT | `chatgpt.svg` (OpenAI's mark) |

**Source.** LobeHub's open-source AI icon set (`@lobehub/icons-static-svg` on npm, MIT licence,
github.com/lobehub/lobe-icons): single-colour vector marks, `fill="currentColor"`, 24 × 24. The
marks belong to Anthropic and OpenAI. Before launch, check each company's brand guidelines for how
the mark may be used.

**To add or replace one:** an SVG with a transparent background, roughly square, cropped tight.
Any colour is fine: the app draws every logo as a silhouette in the ink around it.
