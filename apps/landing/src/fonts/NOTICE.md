# Fonts

Both are licensed under the SIL Open Font License 1.1, which permits bundling and
redistribution. Latin subsets only, variable weight, from Google Fonts via Fontsource. The same
files as the web app's (`apps/web/public/fonts/`); the landing page bundles its own copy, hashed
into `/assets/`.

- **Unbounded** — NARRATIVE (Nikita Kanarev, Mikhail Rudakov). Wide display face. Headings and
  the wordmark. https://fonts.google.com/specimen/Unbounded
- **Space Grotesk** — Florian Karsten. Everything else.
  https://fonts.google.com/specimen/Space+Grotesk
