# P1-T12: REST API (P1 surface)
Status: todo
Depends on: P1-T7, P1-T8, P1-T10, P1-T11
Parallel-safe: yes

## Goal
The web app reads the whole position in one call and makes every P1 write through thin REST
handlers over the Ledger, with architecture §7.2's shapes, the error mapping, the events and an
isolation case per route. The first country confirmation initialises the user's ledger.

## Context
- Read: architecture §5.1 (the web write path: events after the response), §7.2 (routes and shapes;
  writes return `{result, dataVersion, warnings}`), §7.5 (codes and statuses). CONVENTIONS §3, §9
  (the REST and MCP row), §11, §12.
- **Routes in this task:** `GET /api/snapshot`; `POST /api/holdings`; `PATCH` and `DELETE
  /api/holdings/:id`; `GET` and `POST /api/holdings/:id/values`; `PATCH` and `DELETE
  /api/values/:id`; `POST /api/types`, `PATCH` and `DELETE /api/types/:id`; the same for tags;
  `PATCH /api/prefs`. Content routes are P1-T8's, `/api/me` and `/api/geo` P1-T11's, `/api/agent/*`
  P1-T13's.
- **A handler** parses with the contract schema, calls `requireSession`, runs `withUser(userId,
  {kind: 'user'}, …)`, and maps the result. `today` is computed in `profile.time_zone`. Every write
  has `source: web`. `POST /api/holdings` requires `via` (`guided | form`). After the response,
  `Write.events` go to `track()` with the user's segment.
- **Ledger initialisation:** extend `PATCH /api/me` so the first country confirmation calls
  `Ledger.init({baseCurrency: the country's currency, pack})` (generic when the country has no pack)
  in the same request. A later change of country is P3's.
- Log the snapshot's size and value count on each request: the revisit trigger of §7.2 (1 MB gzipped
  or 20,000 values).
- `Cache-Control: private, no-store` on every response here.

## Interface contract
Architecture §7.2's rows for the routes above, exactly, with request and response schemas from
`packages/contracts/src/ledger.ts` (P1-T10). `GET /api/snapshot` honours `If-None-Match: <dataVersion>`
with `304`.

## Files in scope
`apps/api/src/http/{snapshot,holdings,values,types,tags,prefs}.ts`, `apps/api/src/http/me.ts` (the
init step only), `apps/api/test/http/**`.

## Done criteria
- [ ] Every route: a happy path, a validation error naming the fields, not-found, and an isolation
      case (user B with A's ids → `404`, none of A's marker strings in the body). A registry test
      fails when a route has no isolation case.
- [ ] Snapshot: `304` when unchanged; compact values per §7.2.
- [ ] The first country confirmation initialises the ledger once (a second call does not re-init);
      the pack's types appear in the snapshot.
- [ ] `holding_created {source: web, via}`, `value_recorded {source: web}` and `value_corrected` fire
      with the segment, and a privacy test finds no amount in any emitted event.
- [ ] Follows CONVENTIONS.md
