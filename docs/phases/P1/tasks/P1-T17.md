# P1-T17: Web — the Agent tab and the connect flow
Status: todo
Depends on: P1-T13, P1-T14
Parallel-safe: yes

## Goal
From the Agent tab or the empty Home, a person connects Claude or any MCP agent ("Other agent") in
one flow (ChatGPT's guide stays unlisted until NetNet is in OpenAI's directory): choose the agent, follow the steps for their platform with screenshots and the connector URL,
approve on NetNet's approval page, and watch NetNet move on by itself. The Agent tab lists
connections with their client and times, and revokes them.

## Context
- Read: PRD J5 (every criterion but the prompt handoff and the onboarding and holding entries), J1
  (unverified → verify first, with resend, moving on by itself). Architecture §5.1 (the sequence;
  polling every 2 s), §7.2 (`/api/agent/*`), §7.6 (the approval page), §7.8 (`AgentGuide`).
  Design-system §6, §7. CONVENTIONS §13.
- **Prototype reference:** the Agent tab, the connect flow and the approval screen in
  `docs/02-prototype/app.js`, and its `agent` and `pc` tests.
- **Guides are content** (`/api/content/agent/…`), never hard-coded: one list everywhere, `listed`
  only, in `order`. The connector URL is `${PUBLIC_ORIGIN}/mcp`.
- **Platform** (phone or computer) is detected and switchable. "Other agent" has one set of steps,
  no platform switch and no screenshots.
- **The Connect button's** icon turns through the listed guides' logos every 2 s, drawn in the
  button's ink, and holds still under reduced motion; screen readers hear only "Connect to agent".
- **One flow component for every entry.** P1 uses `entry: agent` (the tab) and `entry: home` (the
  empty Home); P2 adds `onboarding` and `holding`.
- **The approval page** `/app/connect/approve` is chrome-less: the registered name (with the DCR
  caveat), Allow and Cancel. Signed out → log in, then back. Unverified → verify first.
- **Failures:** a plain-language cause and Retry for each failed step; never a raw error.
- **Events:** `agent_connection_started {client, entry}` here; completed and failed are server-side.
- Screenshots may be missing until F11: show a neutral placeholder, never a broken image.

## Interface contract
Consumes `/api/agent/*` and the approval API (P1-T13), `GET /api/me`, the content API. Routes:
`/app/agent`, `/app/agent/connect/*`, `/app/connect/approve`.

## Files in scope
`apps/web/src/routes/{agent,connect}/**`, `apps/web/src/components/{ConnectButton,ConnectFlow}*`,
`e2e/agent.spec.ts`, an e2e helper that plays a fake agent (a test OAuth client against the real
server).
