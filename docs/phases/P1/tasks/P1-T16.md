# P1-T16: Web — Home, Add and the holding page
Status: done
Depends on: P1-T12, P1-T14
Parallel-safe: yes

## Goal
A signed-in person sees their position and builds it by hand. Home shows net worth and the
standalone answers (what they could use, what is locked and until when, what they owe) with their
holdings. Add creates an asset or a liability with a value in any currency and settles
accessibility by a fact, a default or "Not sure". The holding page lists values, takes a new one,
changes accessibility, and names who wrote each value.

## Context
- Read: PRD §2.2 (standalone value), J1 (one holding → a total; the first picture states something
  the user did not type), J2 (the Add fields; liabilities; fact questions; the default's reason; the
  consequence, not the label; saving never blocked, asking the agent offered; undecided; a foreign
  currency shows the original amount and hides the rate), J3 (a dated value, back-dated allowed, the
  same-date warning), J6 (the quiet agent mark; the client named when a value is opened).
  Design-system §2.1 (content rules), §6, §7 ("the agent's mark owns the inner left edge").
  CONVENTIONS §5 (every figure from core), §13.
- **Prototype reference:** Home, the Add sheet and the holding page in `docs/02-prototype/app.js`,
  and its `func`, `via`, `content` and `fab` tests.
- **Data:** `GET /api/snapshot` once (TanStack Query, keyed by `dataVersion`), then every figure from
  `packages/core`: `position`, `latestValues`, `staleness`, and `resolveAccess` to preview the
  consequence line. No screen computes a figure itself.
- **The consequence line** is money, computed by core: "counts toward the $X you could use this
  month" or "won't count, it's your home", with the pack's reason in one line.
- **"Ask your agent"** is offered beside the accessibility question. With no agent connected it opens
  the connect flow (P1-T17, `entry: home`); with one, a copyable prompt with no financial data.
- **Empty Home** follows J1's one-primary rule: **Add what you have** as the primary (the Add form in
  P1; the basics in P2), and below a rule the "Let your AI agent do this" block (P1-T17's entry).
- **Not in P1:** charts, the baseline selector, sort and filter, tags, managing types and tags,
  archive and delete in the web, editing or deleting a value, stale labels, the agent handoff cards.
  All P2.

## Done criteria
- [ ] Add: name, kind, type (pack labels), currency (default: the base currency), amount, date
      (default: today); accessibility per J2; saving never blocked; `via: form`.
- [ ] Home: after one add, the total equals that holding's value. Could use, locked (with until) and
      owed come from core. An undecided holding is marked, with a way to decide. Foreign holdings
      show the original amount. Agent-written values carry the quiet mark.
- [ ] Holding page: values newest first, paged; add a value (back-dated allowed; the same-date
      warning shown); change accessibility; opening a value names its writer (you, or the agent's
      name).

      figure one place, no stray cents); the events asserted.
