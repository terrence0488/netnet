# P3-T9: The Insights screen

Status: todo
Depends on: P3-T7
Parallel-safe: yes

## Goal

The person can open Insights and see how each month, quarter and year actually
went — period-end value, change and drivers — through their own filters and
exclusions that persist.

## Context

- PRD J11 is the contract, every bullet; P3-T7 provides `core.periods`
  (computed locally from the snapshot) and the `insightsFilter` /
  `insightsExclusions` prefs keys.
- Insights' filter and Don't Show are separate from Home's, and the screen says
  so (J4). Exclusions persist across sessions until cleared and never change
  Home totals or net worth.
- New users with little history are the normal case in the first weeks: the
  periods they do have plus one plain statement of what a comparison needs,
  with every chart holding its place as Home's placeholder — never an empty
  grid, a fabricated 0% row, or a one-point axis. When filters or exclusions
  leave nothing, the view says that instead, because more data would not help.
- P3-T8 builds the holding bar chart in the same wave from the same engine.
  The two tasks share nothing new: common needs go through `core`, and each
  touches only its own route and components.

## Interface contract

- New route under `/app` (Insights). Monthly, Quarterly and Yearly views, each
  listing net-worth change per calendar period — period-end value, absolute
  change, % change — newest period first. Opening a period shows its drivers
  ranked by contribution in the default currency.
- Insights Filters (type, tag) recompute every figure over the filtered set
  with the active filter visible; the Don't Show list drops a holding, type or
  tag. Both persist via `PATCH /api/prefs` and are labelled as Insights-only.
- `insights_viewed {view}` fires on every view open.

## Files in scope

- `apps/web/src/routes/**` (the new Insights route)
- `apps/web/src/charts/**`, `apps/web/src/components/**` (only components this
  screen needs)
- `apps/web/src/api/**` (prefs client additions)
- `e2e/**` for this screen
