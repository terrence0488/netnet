Parallel-safe: no

## Goal

Every P2 path swept at phone and desktop widths and accessible, the full suites green, and the
phase verified on preview and on production.

## Context

The pipeline, previews and production workflow exist (P1-T1, P1-T18). Production deploys only
from the Founder's manual workflow (decision register). This task is verification plus the
small fixes the sweep finds — not new features. PRD: J1–J4 and J9 happy paths. Binding UI
rules: no sideways scrolling at 320 px; 44 px touch targets (36 px with a fine pointer);
nothing below 11 px on a phone; reduced motion honoured; axe clean on key screens (CONVENTIONS
§9, §13). P2-T8 (phone screenshots) is content-only and off the critical path: this task never
waits for it.

## Interface contract

None new. The bar is the suites: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm test:int`,
`pnpm build`, `pnpm test:e2e` and `pnpm content:check` all green.

## Files in scope

- `e2e/**` (fix and extend the P2 specs)
- Any component the sweep finds broken, fixed small and in place. Anything larger than a
  small fix is stop-and-raise: report it, do not redesign (CONVENTIONS §12).
