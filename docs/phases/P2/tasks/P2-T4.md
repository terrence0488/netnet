Status: done

## Goal

Home shows the whole picture — trend, allocation, breakdowns, baselines, filters, staleness and
the agent handoff — and the empty-Home rule holds with and without a connected agent.

## Context

P1-T16 built the first Home (net worth, what could be used, locked and until when, owed, the
holdings list). This task completes it per PRD J4, the J5 handoff and J9. Figures come from
`core` only: `position`, `series`, `staleness` (P1-T6); use `core.baselineChange(values,
holdings, baseline, today, filter?)` (architecture §7.9) and add it with unit tests if P1 did
not. Baselines and change arithmetic follow the decision register: calendar baselines are month
ends (Jan 1 is 1 January); change is worked out per holding and summed; a holding first valued
after the baseline counts from its first value. Data arrives through `GET /api/snapshot`
(exists, P1); choices persist through `PATCH /api/prefs` (architecture §7.2; add
`Ledger.setPrefs` and the route if P1 did not).

The empty-Home component built here also serves P2-T2's blank Home (agent connected, no
holdings yet). The guide's `prefillUrl` decides prefill-vs-Copy per client (architecture §7.8).

## Interface contract

- The six baselines: Initial value / Last update / Last month / Last quarter / Jan 1 / Last
  year; every change figure and percentage on screen is relative to the one in force, labelled
  (PRD J4).
- Sort by value, name, change or last updated; filter by type or tag; Don't Show for types or
  tags. A type or tag is shown-only or hidden, never both; the active filter is visible and
  names what is hidden; Home's filter is separate from Insights' and says so (PRD J4).
- Handoff: an empty or stale Home hands the next step to a connected agent (the starting
  prompt, or the update prompt naming what is stale) with prefill where the client supports it
  and Copy where not; without an agent the same places offer to connect one. Prompts carry no
  financial data (PRD J5; CONVENTIONS §6).
- Empty rule: no agent → "Add what you have" (the basics) primary, "Let your AI agent do this"
  below a rule; agent connected → the starting prompt, "add it yourself" as the alternative
  (PRD J1).
