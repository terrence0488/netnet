# P4-T20: Purge stale OAuth artifacts on the daily run

Status: todo
Depends on: P4-T13 (the review's L-4)
Parallel-safe: yes

## Goal

The daily job deletes OAuth artifacts past their life — DCR and CIMD clients unused for 30 days,
expired authorization codes and access tokens, revoked or expired refresh tokens, and consents
with no connection — as architecture §6.2 promises, and reports the counts.

## Context

- P4-T13's L-4 (`docs/phases/P4/security-review.md`): architecture §6.2 says "DCR clients unused
  for 30 days are purged"; P1-T13 recorded it as not done and nothing since implements it. The
  daily job sweeps connection attempts and visitor salts only. `core.oauth_client`,
  `core.oauth_client_resource`, `core.oauth_consent`, `core.oauth_access_token` and
  `core.oauth_refresh_token` rows accumulate forever, and P4-T17's CIMD path can create clients
  unauthenticated. The health check alerts at 0.35 GB but cannot stop the growth.
- Architecture §9.3: the daily run is the home for this sweep; it already answers counts only.

## Interface contract

- `apps/api/src/jobs/daily.ts` (or a sibling the daily run calls) deletes, in one transaction per
  class:
  - DCR/CIMD `oauth_client` rows with no access or refresh token and no consent and unused for 30
    days (a named guide's client is not special; all are DCR/CIMD rows);
  - `oauth_client_resource` rows whose client is gone;
  - expired authorization codes and access tokens;
  - refresh tokens revoked or past expiry;
  - consents with no client.
- The run's response adds one count per class (numbers only, no ids); the schedule and its
  existing tests keep their shape.
- Rows inside their window are untouched; a live connection's client, tokens and consent stay.

## Files in scope

- `apps/api/src/jobs/daily.ts`, `apps/api/src/db/**` (the deletes and their queries)
- `apps/api/src/auth/**` only if a table name or helper lives there
- `apps/api/test/jobs/**`, `test/schedules/**`
- `docs/03-architecture.md` §6.2 only if the window needs restating

## Done criteria

- [ ] Each class is deleted past its window and kept inside it, with fixed clocks
- [ ] A live agent connection's client, tokens and consent survive the sweep
- [ ] The daily response reports the counts, and no id or personal data appears in them
- [ ] `pnpm test`, `pnpm test:int`, `pnpm typecheck` and CI pass
- [ ] Follows CONVENTIONS.md
